## Runtime dependencies (not bundled)

The pack has no Python dependencies of its own (`dependencies = []`). At run time it uses packages of the ComfyUI environment; they are installed with ComfyUI, not with this pack, and the pack makes no changes to them.

| Package | Used for | License |
|---|---|---|
| ComfyUI and its frontend | the host application | GPL-3.0 |
| PyAV (`av`) | ND Load Video / ND Load Audio, ND UI Live Bridge (video and sound) | BSD-3-Clause; the binary wheels from PyPI bundle FFmpeg libraries, which are under the LGPL-2.1-or-later (or the GPL, depending on how they were built) |
| NumPy | images and audio as arrays | BSD-3-Clause |
| Pillow (`PIL`) | previews of models and images | MIT-CMU (historical PIL license) |
| PyTorch (`torch`) | tensors passed between ComfyUI nodes | BSD-3-Clause |
| aiohttp | the small HTTP routes of the pack, through the ComfyUI server | Apache-2.0 |
