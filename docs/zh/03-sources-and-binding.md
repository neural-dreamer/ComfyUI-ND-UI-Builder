# 源与绑定

## 源

**源**是节点图中面板可以读取和修改的节点。有两种方式创建：

- **标题中的标签。** 把节点命名为 `名称 [标签]`。标签是面板用来识别该节点的稳定名称。把工作流复制到别的文件后标签依然保留，因此模板或项目可凭标签重新找到节点。
- **从编辑器添加。** 在**关联**标签中点击**在画布上选择**并点击节点，或在节点图中选中节点后点击**添加所选**。标签由编辑器自动添加。

一个面板可以使用多个节点。在节点图中调整顺序或重命名节点不会破坏面板。

## 绑定

控件有**插槽**。插槽是放置一个参数的位置：例如**提示词**控件有插槽 *值*，**分辨率**控件有 *宽度* 和 *高度*。在设置的**数值**部分选择插槽，再选择源和参数；也可以点击**在画布上选择**，直接点节点上的参数。

控件显示参数的真实值，并把你的修改写回节点，所以节点图和面板始终一致。在 [控件](04-widgets.md) 中带星号的插槽必须绑定；未绑定时控件会显示提示。

另一类插槽接收的不是数字或文本，而是节点的**结果**：图片、实时运行的画面、文本、视频。它们只列出能提供这些结果的节点。

## 虚拟参数

Neural Dreamer Nodes 中的 **ND Slider** 和 **ND Resolution** 节点把数值存放在一个隐藏字段里。面板把它们显示为普通参数：滑块对应 *value*，分辨率对应 *width* 和 *height*。对 ND Resolution 节点使用**在画布上选择**，会得到一个**分辨率**控件。

## 提示

每个带绑定的控件都有**提示**字段。在 ND UI 模式中，指针在控件上稍作停留后会显示该文字。

## 缺失的节点

如果节点被删除或找不到其标签，控件会显示未绑定。重新绑定即可，其他内容不受影响。
