# 控件

控件库中的所有控件，按分组排列。名称与编辑器中显示的一致。**插槽** 是控件所绑定的参数（或节点结果），带 * 的插槽必须绑定。**属性** 是检查器中的设置。

### LoRA 堆栈

Neural Dreamer Nodes 的 LoRA 堆栈，带预览图库。需要 ND LoRA Stack 节点或 **ND LoRA Stack H3 Temporal** 节点。

使用 H3 Temporal 节点（Neural Dreamer Nodes **1.4.0** 或更新版本）时，每张卡片都有一个时钟按钮：直接在卡片中打开该 LoRA 的时间设置（区间、淡入淡出、音频），信息窗口会显示该 LoRA 在 MiniMax H3 模型中修改的内容。控件会保留堆栈中它未显示的所有设置。

**插槽:** ND LoRA Stack 节点 \*

**属性:**

| | 默认 | |
|---|---|---|
| 显示 CLIP 滑块 | 关 | 关闭：CLIP 强度跟随模型强度（只要二者保持关联）。 |
| 滑块最小值 | -1.5 | 模型和 CLIP 强度相同。手动输入的数字不受限制。 |
| 滑块最大值 | 1.5 | 模型和 CLIP 强度相同。手动输入的数字不受限制。 |
| 强度的 ◀ ▶ 箭头 | 开 | 步长 0.05；按住 Shift 步长更大（0.25）。按住箭头可连续调整。 |
| 视频预览 | hover | 适用于预览为视频的 LoRA（Neural Dreamer Nodes）。始终静音；不播放时显示第一帧。 |
