# 布局

## 页面与尺寸

一个面板可以有一个或多个**页面**；页面名称以标签形式显示在模式顶部。在页面设置中可设置**比例**（16:9、4:3、自由等）、编辑器中的**宽度和高度**、**圆角**以及**长度**：长度大于窗口时页面可滚动，**0（自动）**则按内容适配。

**在窗口中**决定页面在 ND UI 模式中的表现：

- **比例**：页面保持比例并整体缩放。
- **填满窗口**：页面拉伸以填满窗口。
- **适应窗口**：页面保持控件的大小，并把剩余空间分配给它们之间；大面积区域（查看器、提示词、面板、图片、视频、嵌入节点）会增长，占满窗口的宽度和高度。

**背景填满窗口**会用页面背景（主题渐变、颜色、图片）铺满整个窗口，页面周围没有可见的边框。

## 容器

- **面板**：一个边框。放在上面的控件随它一起移动。
- **折叠框**：可折叠和展开的边框，适合放高级设置。
- **标签页面板**：带标签页的边框，每个标签页有各自的控件。
- **标签页**：可放在任意位置的页面标签。
- **标题**、**文本块**、**分隔线**、**图片**：装饰元素。

把控件拖到容器上即可放入其中，也可以在编辑器的**布局**栏中移动：行的上三分之一表示*上方*，下三分之一表示*下方*，中间表示放*入*面板、折叠框或分组。

## 分组

选中多个控件，按 **Ctrl+G** 分组。分组作为整体移动、复制和删除。双击分组可逐个操作其中的控件，**Alt+点击**选中单个控件。**Ctrl+Shift+G** 取消分组。图层列表中分组带有眼睛和锁。分组位于同一页面、同一层级（不能分组套分组）。

## 对齐与均匀分布

选中两个或更多控件时，设置的布局部分提供**对齐**（左、中、右、上、中间、下）和**均匀分布**（行或列中的等间距，可设置边距和间隔）。这些值会在不同会话间保留。

## UI Scale

放置一个 **UI Scale** 控件，即可随时放大或缩小页面（适合小屏幕或电视）。
