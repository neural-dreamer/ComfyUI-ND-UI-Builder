# 编辑器

点击 Run 旁边的 **Edit** 打开编辑器。它是一个全屏窗口，分为三栏。

## 左栏

- **关联**：**源**列表，即面板所控制的节点。**在画布上选择**可在节点图中点击节点来添加；**添加所选**会添加已选中的节点。每个源都可以展开，查看其参数。见 [源与绑定](03-sources-and-binding.md)。
- **控件**：控件库，分为四组（**输入**、**运行**、**结果**、**布局**），另有用于 ND UI 模式按钮的**顶栏**组。点击图块会把控件添加到页面末尾，拖动则可放到指定位置。
- **布局**：当前页面的图层。每个控件和分组都是一行，带有可见性眼睛和锁。可拖动行来重新排序，或嵌入分组、面板、折叠框。见 [布局](05-layout.md)。

## 画布

页面按所选比例绘制。点击选中控件，拖动移动，拖动手柄调整大小。按住 Shift 点击或拖出矩形可多选。常用快捷键可用：**Delete**、**Ctrl+Z / Ctrl+Y**、**Ctrl+C / Ctrl+V**、**Ctrl+G**（分组）、**Ctrl+Shift+G**（取消分组）。右栏布局部分的**对齐**和**均匀分布**工具可把选中的控件排成等间距的一行或一列。

编辑器顶部有页面标签（用 + 添加页面）、撤销与重做、缩放、**预览**（无需离开编辑器即可试用面板）、**取消**和**保存**。

## 右栏

三个标签：

- **设置**：未选中任何内容时是整个页面的设置：比例、尺寸、圆角、背景、**主题**、顶部面板外观、模式的进度条、模式按钮（内存按钮、项目按钮、ComfyUI 按钮）。选中控件时是该控件自己的设置：绑定对象（**数值**）、提示、外观，以及 [控件](04-widgets.md) 中列出的属性。
- **模板**：现成页面和你自己的模板。见 [项目与模板](11-projects-templates.md)。
- **编辑器**：编辑器本身的外观（强调色、侧栏、顶栏、画布背景）。**恢复默认外观**可还原默认值。

## 保存

**保存**会把面板写入工作流（随工作流文件一起保存）。**取消**会放弃本次编辑器会话中的修改。也可以把整个面板另存为单独的**项目**文件，见 [项目与模板](11-projects-templates.md)。
