# 嵌入节点

有些节点有自己的界面：预览、遮罩编辑器、画布、自定义控件。**嵌入节点**（Node Embed）把这个界面显示在面板内，无需再回到节点图。

## 用法

1. 添加**嵌入节点**控件（*输入*组）。
2. 把它的插槽绑定到该节点。
3. 控件会显示节点的实时界面。在面板中所做的修改会写入节点。

## 外观

*Recolour to the theme* 会把节点原本灰色或深色的界面重绘为当前主题的颜色，对半透明的霜和玻璃主题同样有效。

## 限制

- 只能显示节点在自己控件中绘制的内容。位于节点之外的其他插件面板无法显示。
- 有些节点会自行决定大小；可在页面上拉大控件为它们留出空间。
- 嵌入的是真实界面：缓慢或沉重的节点在面板中也一样慢。
