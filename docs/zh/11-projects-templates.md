# 项目与模板

## 项目

**项目**是整个工作流连同它的面板保存成的一个文件（默认类型 `.ndui`）。输入文件以引用形式保存，不会复制进去。

- 模式右上角的软盘按钮用于保存（**Save**），并带有小菜单：**Save as**、**Open**。
- 在基于 Chromium 的浏览器中，第一次保存会询问文件位置，之后写入同一文件。
- 设置 **ComfyUI ND UI Builder → Project files → Open a project** 决定项目是**在新标签页**中打开（默认）还是**替换当前工作流**。
- 按钮的位置、是否显示以及文件类型在页面设置的 *View* 部分设置。

## 模板

在编辑器右栏的**模板**标签中有：

- **现成页面**：四种内置布局，带缩略图。点击 **+** 或双击即可作为新页面添加。
- **我的模板**：你自己的页面和整个面板。把鼠标移到图块上会出现 **+**（应用）和 **⋯**（重命名、新图片、导出、删除）。
- **另存为模板**：选择*仅此页面*或*整个面板及所有页面*，以及用作缩略图的页面。

模板通过节点的 `[标签]` 进行绑定，因此在有相同标签节点的其他工作流中同样可用。未找到的节点会在消息中列出。应用整个面板会要求确认，并可用 **Ctrl+Z** 撤销。模板存放在 ComfyUI 用户文件夹中（`user/default/ndui-templates`）。**导出**和**导入**以 `.ndui.json` 文件传输面板。

## 工作流切换器

打开多个工作流时，按 **Alt+Q**（按住 Alt，点按 Q 逐个切换，松开 Alt 完成切换；Shift 反向）。卡片显示每个 ND UI 面板的缩略图或节点图。logo 旁的按钮可打开同一个切换器。

## 运行到节点

**运行到节点**控件只运行工作流到所选节点为止，适合试跑长工作流的前半部分。
