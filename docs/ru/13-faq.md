# Частые вопросы

**Не вижу кнопок ND UI и Edit.** Обновите страницу через Ctrl+F5. Проверьте настройку *ComfyUI ND UI Builder → Buttons → Action bar → Show the ND UI and Edit buttons next to Run*.

**Виджет пишет, что не привязан.** Нода или её метка не найдены. Откройте редактор, вкладку **Привязка**, и привяжите виджет заново.

**Просмотр не показывает живых кадров.** Поставьте **ND UI Live Bridge** на провод модели перед сэмплером и убедитесь, что у виджета Просмотр включено *live* и глаз открыт. Обычные превью ComfyUI в панель не попадают.

**Нет кнопки динамика.** Мосту нужен `audio_vae`. Без него звук выключен.

**Виджет просит установить Neural Dreamer Nodes.** См. [Neural Dreamer Nodes](12-neural-dreamer-nodes.md). Для Превью вариантов нужна версия 1.3.1 или новее.

**Горячие клавиши ComfyUI в режиме не работают.** Так задумано. Разрешите команды в настройках ComfyUI, *ComfyUI ND UI Builder → ND UI mode*.

**Страница тормозит на слабом компьютере.** Выберите тему без размытия (Полночь, Студия, ComfyUI) или отключите *Использовать размытие*.

**Какой ComfyUI нужен?** Пак проверен на фронтенде 1.55 и 1.57. На более старых могут не работать некоторые функции.

**Воркфлоу не запускается по Generate.** Generate ставит в очередь воркфлоу ровно таким, каков граф. Проверьте, что в самом графе нет ошибок (выйдите из режима и посмотрите на красные ноды).

**Где хранится панель?** В файле воркфлоу, то есть вместе с ним. Файл проекта (`.ndui`) хранит панель и воркфлоу одним файлом.
