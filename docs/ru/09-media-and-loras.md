# Медиа и LoRA

## Картинки

- **Simple Load Image**: одна картинка. Перетащите файл, вставьте из буфера или выберите из папки input. Работает с обычной нодой Load Image.
- **Images Input**: одна или несколько картинок с превью, порядком и маской. Нужна нода **ND Load Images** из Neural Dreamer Nodes.

## Видео и звук

- **Ввод видео** и **Ввод аудио** загружают видео или звук с плеером и полосой обрезки. Им нужны ноды **ND Load Video** и **ND Load Audio**.
- **Видеоплеер** и **Аудиоплеер** проигрывают результаты. С Live Bridge Видеоплеер показывает и кадры, пока сэмплер работает.

## Текст

**Вывод текста** показывает текстовый результат ноды. **Show Any As Text** это родной вид ноды **ND Show Any As Text**: вкладка *Preview* со значением последнего запуска и ваши заметки на следующих вкладках.

## Модели

**Выбор модели** это выбор с папками и поиском для любого параметра со списком файлов моделей (checkpoint, diffusion model, VAE).

## LoRA

- **Стек LoRA** работает с нодой **ND LoRA Stack** из Neural Dreamer Nodes: галерея превью (картинки или видео), силы, триггер-слова и NSFW-фильтр для превью.
- **Выбор LoRA** управляет одной LoRA обычной ноды **LoRA Loader**: файл с превью и две силы.
