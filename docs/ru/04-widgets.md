# Виджеты

Все виджеты библиотеки по группам. Названия такие же, как в редакторе. **Слоты** — параметры (или результаты ноды), к которым привязан виджет; слот со звёздочкой * привязать нужно. **Свойства** — настройки в инспекторе.

**Слоты:** Значение \*
