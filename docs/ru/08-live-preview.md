# Живое превью

Живое превью показывает картинку (или видео) в вашей панели, пока сэмплер ещё работает.

## Просмотр

Виджет **Просмотр** (Viewer) показывает готовые картинки ноды, живые кадры запуска, масштабируемый вид и ползунок сравнения **A / B**. В настройках включите *live*, *results* или *compare* по необходимости. Пока кадра нет, он может показывать анимированный значок *While it works*.

## ND UI Live Bridge

Нода **ND UI Live Bridge** (категория *Neural Dreamer/UI*) следит за сэмплером и передаёт панели его промежуточную картинку. Поставьте её на **провод модели**: загрузчик модели (или последний патч модели) → **ND UI Live Bridge** → сэмплер. Она пропускает модель без изменений и только наблюдает за шагами. Настройки:

| Вход | Что делает |
|---|---|
| `tiny_vae` | как латент превращается в картинку: `auto`, `latent2rgb` или файл `taesd` из `vae_approx` |
| `size` | длинная сторона живой картинки в пикселях (по умолчанию 384) |
| `preview` | `first frame` или `animated` (короткий клип из всех кадров видео) |
| `fps` | частота кадров анимированного превью |
| `interval` | секунды между двумя превью; последний шаг показывается всегда |
| `max_frames` | самый длинный клип |
| `audio_vae` | необязательный: декодировать звук аудио-видео модели, чтобы у превью был звук |

Мост тратит время, только пока на него смотрит что-то в панели (или нода **ND UI Live Preview**). Закрытый глаз или скрытый виджет ничего не просят. Превью никогда не занимает больше примерно четверти шага.

Звук: кнопка динамика и ползунок громкости появляются, только если у моста есть `audio_vae`. По умолчанию звук выключен.

## ND UI Live Preview

Нода **ND UI Live Preview** показывает ту же живую картинку прямо на графе. У неё один вход (`live`, второй выход Live Bridge) и нет настроек. Глаз, динамик и громкость хранятся в ноде.

## Видеоплеер и Аудиоплеер

**Видеоплеер** проигрывает видео ноды и показывает живые кадры во время запуска. **Аудиоплеер** проигрывает звук ноды. См. [Виджеты](04-widgets.md).

## Превью вариантов

С Neural Dreamer Nodes 1.3.1 или новее виджет **Превью вариантов** (Variant Preview) приносит варианты **ND Variant Preview Selector** прямо в панель, с живыми кадрами и кнопкой Upscale. См. [Neural Dreamer Nodes](12-neural-dreamer-nodes.md).
